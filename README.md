# DemoBank — static demo site

An **original**, fictional retail-bank website ("DemoBank") used to show how a site can be deployed straight from a public Git link.
It is **not** a copy of any real bank's site, branding or layout. Names, rates and text are placeholders; every form is an inert sample
that submits nothing; a ribbon and the login page say it is a demonstration.

Pages: home, accounts, cards, loans, business, product details, rates, branches, about, contact, open-account and a sample internet-banking login.
There is no build step, so any web server can serve this folder as it is.

## Deploy it

In App Stacks, create a **Static website** stack and paste this repository's link as the Git source.

## Make it yours

Change the brand name, colours (top of `assets/style.css`) and text to your own. Keep the demo ribbon until the content is real.
